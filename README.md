# Promos Bancarias

Aplicación para centralizar y consultar promociones bancarias y de billeteras virtuales disponibles en Argentina.

## Objetivo

Este proyecto busca facilitar el ahorro pudiendo encontrar de manera rápida y sencilla las distintas promociones de todos los métodos de pagos posibles para cualquier comercio.

La idea es evitar tener que revisar individualmente las páginas o aplicaciones de cada banco, billetera o comercio para encontrar promociones vigentes.

## Funcionalidades previstas

* Consultar promociones para un comercio.
* Filtrar promociones por medio de pago.
* Filtrar por categoría o comercio.
* Mostrar vigencia, días disponibles y condiciones de cada promoción.
* Mantener actualizada la información de las promociones.
